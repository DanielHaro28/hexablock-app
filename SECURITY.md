# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub: go to the **Security** tab of this repository and click **Report a vulnerability** ([GitHub docs](https://docs.github.com/en/code-security/security-advisories/guidelines-for-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)). Only the maintainers can see the report.

Include what you found, how to reproduce it and what an attacker could do with it. Never include real passwords, tokens or other people's data.

We will answer within 7 days. This is a university project maintained by three students, so there is no bug bounty.

## Supported versions

Only the latest release (the APK in GitHub Releases) receives fixes.
