# ComboToast

ComboToast celebrates a combo, a cleared stack, a merge or a completed figure, 96 dp above the board for 1.2 s.

**Provide:** `title` («¡Combo ×3!», «¡Doble línea!», «¡Pila completa!», «¡Fusión 512!», «¡Figura completa!»), `value` («+120», «Meta 4/5», «3 ★»), optional `petals`.

- 56 high, `surface` pill with a 2 px `butter` border and `shadow-soft`; star icon; value in a `butter` pill, Fredoka 16.
- Enters from 16 px above in 220 ms, stays 1.2 s. With Reduce Motion: fade only, no petals.
