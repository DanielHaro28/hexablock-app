# Icon

Icon is the suite's line icon set: 24 grid, 2.2 px round strokes in `ink`.

**Provide:** `name` (play, retry, undo, rotate, sound, hint, shuffle, music, stats, pause, home, back, settings, goal, check, moves, time, star, lock, help, more, alert, star-filled), optional `size` (24 in buttons, 18 in chips, 16 in cards) and `color` (a token name; `ink-soft` only when disabled), `label` when the icon stands alone.

- `help` («?») opens «Cómo jugar» / «How to play»; `more` opens a Menu; `alert` marks a field error, always next to its message.
